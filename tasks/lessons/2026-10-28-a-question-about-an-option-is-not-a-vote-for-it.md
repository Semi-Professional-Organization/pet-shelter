# A question about an option is not a vote for it

**Learned:** 2026-10-28

The owner asked for stat numbers "the same blue as nav bar". Light blue on white is 1.6:1, so I
offered three options with a "chip" (a blue pill behind each number) marked recommended. The owner
replied "what does chip mean?", then "the number and pill can stay blue". I read that as choosing
the pill and built it. They had not chosen it, and the answer was "revert the blue pill i dont
want pill".

**Rule:** when the owner has to ask what an option means, they have not picked it. Before building
a visual change they did not name themselves, show it first (a screenshot of the actual page,
not an ASCII preview), or offer it as a single yes/no. If an answer only half-fits the options,
build the part they stated in their own words.
