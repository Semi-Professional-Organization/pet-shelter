# A summary of review rounds is a claim; tally them before stopping on it

**Learned:** 2026-10-15

PR #104's review loop was stopped on the sentence "rounds ten, eleven and twelve each found only
wording, never code". Round thirteen showed round ten had found false facts. The correction then said
"only rounds eleven and twelve were wording-only", and round fourteen showed round twelve had found
false facts too. Only round eleven was wording. Both summaries were written from the impression the
rounds left, not from their recorded findings, and both erred in the direction that justified
stopping. Read from the record, four of five late rounds had found something false in text written
to fix the round before — the case *for* continuing.

**Rule:** before stopping a review loop, or before writing any sentence that characterises several
rounds at once ("only nits", "never code", "all fixed"), build the per-round table from each round's
recorded findings and write the sentence from the table. A ledger fix is not exempt from review
because it is prose: here, prose fixes were where the new false claims kept appearing.
